# 代理式轉變準備檢查表（Preparing for the Shift）

依 K118 第 2 章檢查表的三個動作：**分類 backlog（Agent 輔助型／人類主導型）→ 重估時間 → 調整 PR 審查**。

> 團隊與 backlog 是虛構的（一家 8 人 SaaS 團隊）。書上這一節沒有給具體百分比或工時，下表所有工時數字都是**假設值**，僅示範「重估」該怎麼做。

## A. 開工前的準備項目

- [x] 有自動化測試，且「改之前是綠的」（本練習：Jest 16 個測試）
- [x] 有明文的慣例檔讓代理遵循（本練習：`src/lib/errors.ts` 的錯誤處理慣例；團隊層級應寫進 `CLAUDE.md`）
- [x] 權限邊界寫在專案層設定（本練習：`.claude/settings.local.json` 禁止改 `tests/`、禁止 `git push`）
- [x] 公開 API 有明確入口（`src/index.ts`），「不准改」的範圍說得出來
- [ ] 團隊有共識：哪些任務類型預設交給代理（見下方 B）
- [ ] PR 範本加上「代理產出」欄位與審查重點（見下方 D）
- [ ] 估時方式改版（見下方 C），至少觀察 2 個 sprint（假設值）再定案

## B. Backlog 分類（8 個虛構任務）

判斷原則：**規格清楚、有測試能驗證、錯了容易回復** → Agent 輔助型；**需要商業判斷、跨團隊協商、高風險不可逆、或「要做什麼」本身還不清楚** → 人類主導型。

| # | 任務 | 分類 | 理由 |
| --- | --- | --- | --- |
| 1 | 把付款模組從 switch 重構成 strategy pattern（本練習實際做過） | **Agent 輔助型** | 目標明確、公開 API 有測試保護，代理可跑完整 Observe→Verify 迴圈；本次實測 113 秒完成且行為一致 |
| 2 | 替舊的訂單匯出模組補單元測試，覆蓋率 40% → 80%（假設值） | **Agent 輔助型** | 書第 4 章列單元測試為高回報任務；成果可量化（覆蓋率），審查只需看測試是否有意義 |
| 3 | 全專案把 `moment.js` 換成 `date-fns` | **Agent 輔助型** | 機械式、跨很多檔案，正是代理擅長的多檔修改；靠型別檢查 + 測試把關，人類抽查時區相關的邊界 |
| 4 | 新增資料庫欄位與遷移腳本（`users.locale`） | **Agent 輔助型（需人類核准上線）** | 書第 4 章列資料庫遷移為高回報；但遷移在正式庫不易回復，代理寫腳本與 down 遷移，**執行**由人類決定 |
| 5 | 決定要不要從單體拆出計費微服務 | **人類主導型** | 架構取捨牽涉組織、成本與團隊能力，代理可幫忙蒐集資料與列方案，但決策要人負責 |
| 6 | 調查「部分客戶偶發重複扣款」的線上事故 | **人類主導型** | 涉及真實金流與客戶溝通，需要看正式環境資料、判斷影響範圍；代理可協助讀 log、寫重現測試，但指揮與對外說明是人 |
| 7 | 依新法規修改個資保存期限與刪除流程 | **人類主導型** | 需求來自法務解讀，錯了有法律風險；先由人定規格，實作細節再拆小塊交給代理 |
| 8 | 和合作銀行對接新的退款 API（規格文件還在協商） | **人類主導型** | 「要做什麼」還沒定，代理沒有可遵循的規格；等規格定案後，串接程式碼可轉為 Agent 輔助型 |

結果：4 項 Agent 輔助型、4 項人類主導型。注意 #4、#6、#8 都是「混合」：同一個任務裡，判斷與決策歸人，可驗證的實作歸代理。

## C. 重新估時（假設值示範）

| # | 原估（人類獨做） | 新估（Agent 輔助） | 新估的組成 |
| --- | --- | --- | --- |
| 1 | 1 天 | 0.25 天 | 寫提示詞 + 代理執行 + 人類審 diff |
| 2 | 3 天 | 1 天 | 審查測試品質是主要工時 |
| 3 | 2 天 | 0.5 天 | 時區邊界要人工抽查 |
| 4 | 1 天 | 0.5 天 | 上線核准與觀察時間不變 |

重點不是數字本身，而是**工時結構變了**：從「寫程式」轉移到「寫清楚的規格 + 審查」。人類主導型（#5～#8）原估不變。

## D. PR 審查機制調整

- [ ] PR 範本加「是否為代理產出」與「使用的提示詞」欄位，方便追溯
- [ ] 代理產出的 PR，審查重點放在：有沒有改到不該改的範圍、測試是不是真的在驗行為（不是被改成配合程式）
- [ ] 測試目錄、錯誤慣例檔、CI 設定用權限 `deny` 保護，代理改不到（本練習已示範）
- [ ] 代理不能自己 commit / push，最後一步一定是人類（本練習用 `--disallowedTools` 示範）
- [ ] 大型重構要求附「差分驗證」證據（本練習：新舊版 378 組輸入比對）
