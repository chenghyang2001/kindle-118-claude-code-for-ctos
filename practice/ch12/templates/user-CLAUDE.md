# ~/.claude/CLAUDE.md（User 層範本）

> 這是範本，**不會**被 Claude Code 自動載入。要使用時自行複製到 `~/.claude/CLAUDE.md`。
> User 層只放「跨所有專案都成立」的個人偏好；專案規則寫在專案根目錄 CLAUDE.md。

## 溝通

- 一律用繁體中文回覆；程式碼本體與技術名詞保留英文。
- 回報先講結果，再講細節；不確定就明講假設。

## 工作方式

- 動手前先讀相關檔案，不憑記憶猜 API。
- 改完程式先跑專案的測試與 lint，失敗要回報原因，不要假裝通過。
- 只做被要求的範圍；額外建議列在最後，不要順手大改。

## 個人程式風格（專案 CLAUDE.md 有規定時以專案為準）

- 命名要表達意圖，避免 `data`、`tmp`、`result` 這類含糊名稱。
- 錯誤處理不可只寫快樂路徑。
- 註解寫「為什麼」。

## 安全

- 不把 API key、token 寫進程式碼或 commit；一律用環境變數。
- 不執行破壞性指令（`rm -rf`、`git reset --hard`、force push）除非明確要求。
